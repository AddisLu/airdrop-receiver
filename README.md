# 傳到電腦（Windows 版 AirDrop 接收器）

從 iPhone／iPad 的分享選單把**任何檔案**傳到這台 Windows 電腦，用起來就像 AirDrop。照片、影片、PDF、Office 檔、LINE 裡的檔案都可以。

- **開機就能接收**：不用登入，背景的排程工作就會開始接收。
- **直接存到「下載」資料夾**，同名檔案會自動改名，不會覆蓋。
- **系統匣圖示**：收到檔案時跳出通知，點通知會在檔案總管中選取該檔案；收到的文字或連結會自動複製到剪貼簿。

### 支援哪些項目（對照 AirDrop）

| 從 iPhone 分享 | 電腦上的結果 |
|---|---|
| 照片、影片（相簿可多選） | 存進「下載」，保留原檔名 |
| 任何檔案：PDF、Office、壓縮檔，以及 LINE、檔案 App、Mail 附件等 | 存進「下載」 |
| **網址**（Safari、LINE、YouTube、地圖等任何 App 的「分享連結」），或在網頁上貼上的連結 | **直接用預設瀏覽器打開**（和 Mac 收到 AirDrop 連結一樣），也會複製到剪貼簿 |
| 文字（備忘錄、選取的文字），或在網頁上貼上的文字 | 複製到剪貼簿，並記錄在 `下載\傳到電腦-文字.txt`；從捷徑分享時會另外存成 .txt |
| 聯絡人 | 存成 .vcf，可以匯入 Outlook／People |

### 電腦傳到 iPhone

在電腦上有三種方式可以把檔案放進「iPhone 收件匣」：

- 在檔案總管對檔案（可多選，也可以選資料夾，會自動壓縮成 .zip）按右鍵 → **傳送到 → iPhone（傳到電腦）**。Windows 11 要先點「顯示更多選項」。
- 系統匣圖示按右鍵 → **傳檔案到 iPhone…**
- 在設定頁的「傳到 iPhone」卡片上選擇檔案，或直接拖放。

在 iPhone 上有兩種方式接收：

- 打開「傳到電腦」捷徑 → **從電腦接收檔案**。照片和影片會存進「照片」，其他檔案會詢問要存到「檔案」App 的哪裡。
- 或打開手機上的「傳到電腦」網頁，在「從電腦接收」點「下載」。

iPhone 收到後，電腦會跳通知「iPhone 已接收」。已接收的項目一天後自動清除，沒被接收的項目七天後清除。

**ntfy 推播，一鍵接收**：電腦一放進檔案，iPhone 的 ntfy App 就會跳出「電腦傳來 N 個檔案」。**點一下通知**，「從電腦接收」捷徑就會自動把所有檔案下載好：

- 照片、影片自動存進「照片」。
- 其他檔案自動存到「檔案」App › iCloud 雲碟 › **Shortcuts** 資料夾。
- 不會出現選單，也不會詢問存放位置。

設定（手機網頁上的「電腦傳檔時一鍵接收」卡片）：

1. 按「複製主題」，再到 ntfy App →「＋」→ 貼上 →「訂閱」。
2. 按「安裝接收捷徑」→「加入捷徑」。**不用貼任何東西**，但名稱必須保持「從電腦接收」，因為通知是用這個名稱啟動捷徑的。

第一次接收時，iPhone 會詢問「允許連線到 <電腦 IP>」和「允許取用照片」，請都選允許。

如果出現「請選擇此動作中每個參數的值」：點「顯示」，看哪個動作被標紅，再截圖回報。（1.6.0 以前判斷「是不是照片」的「如果」會出現這個錯誤；1.6.1 起捷徑裡已經沒有這個判斷。）

**存好才算收到**：「從電腦接收」把每個檔案存好之後，才會通知電腦「已接收」。中途失敗（例如還沒設定資料夾）的檔案會留在收件匣，下次點通知會再拿一次。用網頁或「傳到電腦」選單下載的檔案，則是下載當下就算已接收。

運作方式與安全性：

- 每則推播會附上一張**臨時下載通行證**（`?ticket=…`，3 天後失效）。它只能讀取和下載收件匣，不能上傳，也不能讀剪貼簿。真正的 Token 不會經過 ntfy。
- 推播經過 `config.json` 裡的 `ntfyServer`（預設 https://ntfy.sh），內容只有檔名和這張通行證，**不含檔案本身**。
- 推播裡的位址預設是電腦的區域網路 IP，所以 iPhone 要連在家裡的 Wi-Fi 才能接收。如果想在外面也能透過 Tailscale 接收，在 `config.json` 加上 `"pushAddress": "100.x.y.z"`（電腦的 Tailscale IP），再重新啟動服務。
- 主題 `ntfyTopic` 是隨機產生的，請不要公開。如果改用自架的 ntfy，改 `ntfyServer` 後重新啟動服務即可。
- iOS 不允許在收到通知時自動執行捷徑，所以「點一下通知」是最少的步驟。通知上的「開網頁下載」按鈕則會打開手機網頁的收件區。

### 雙向剪貼簿

直接打開捷徑（不是從分享選單啟動）時會出現選單：

| 選項 | 作用 |
|---|---|
| 從電腦接收檔案 | 見上一節 |
| 拿電腦的剪貼簿 | 電腦上拷貝的文字或圖片 → iPhone 剪貼簿 |
| 把剪貼簿傳到電腦 | iPhone 上拷貝的文字或圖片 → 電腦剪貼簿，可以直接 Ctrl+V |
| 選照片傳到電腦 / 選檔案傳到電腦 | 不用先打開其他 App 就能傳 |

**建議設定「輕點背面」**：設定 → 輔助使用 → 觸控 → 輕點背面 → 輕點兩下 → 選「傳到電腦」。之後在 iPhone 背面敲兩下，就會跳出上面的選單。

隱私：

- 只有 iPhone 要求時，系統匣程式才會讀取電腦剪貼簿，而且每次都會跳通知「已把剪貼簿傳給 iPhone」。
- 剪貼簿內容不會寫進收件紀錄。
- 剪貼簿功能需要電腦已登入（系統匣程式在執行）；開機但還沒登入時，只能傳檔案。

不想讓連結自動打開的話，在 `config.json` 加上 `"openLinks": false`，然後從系統匣選單結束程式再重新開啟。
- **安全性**：每次傳送都要附 Token，防火牆只開放區域網路和 Tailscale。

> 為什麼不是真正的 AirDrop：AirDrop 走 Apple 的 AWDL 無線協定，Windows 和 Intel 網卡都不支援，所以改用 HTTP 傳輸。

## 安裝（只要一次）

需求：Windows 10/11，不需要另外安裝任何軟體（PowerShell 5.1 和 .NET Framework 都是 Windows 內建的）。

1. 下載或 `git clone` 這個專案，放到一個固定的資料夾（例如 `C:\Tools\airdrop-receiver`）。
2. 按兩下 **`安裝.cmd`**，在「是否允許變更」視窗按「是」。

或者在**系統管理員** PowerShell 中執行：

```powershell
powershell -ExecutionPolicy Bypass -File <專案資料夾>\install.ps1
```

安裝程式會：

1. 註冊排程工作 `AirDropReceiver`：開機時以你的帳號在背景執行（不需要登入），當掉時每分鐘自動重新啟動。
2. 在「啟動」資料夾和開始功能表建立「傳到電腦」捷徑，登入後出現系統匣圖示。
3. 設定網路權限（URL ACL），並建立防火牆規則：TCP 8765，只限區域網路和 100.64.0.0/10（Tailscale）。
4. 把儲存位置設成你的「下載」資料夾，寫入 `config.json`。

裝好後會自動打開設定頁。之後隨時可以在系統匣的藍色圖示上按兩下開啟。

- 修改程式或設定後：再執行一次 `install.ps1` 即可。
- 移除：在系統管理員 PowerShell 執行 `uninstall.ps1`，收到的檔案不會被刪除。
- 請不要搬動這個資料夾；如果要搬，搬完再執行一次 `install.ps1`。

## iPhone 設定

### 1. 網頁（最快）

用 iPhone 相機掃描設定頁上的 QR Code，然後在 Safari 點「分享 → 加入主畫面」。之後點這個圖示，就能選照片／檔案或傳送文字。

### 2. 捷徑：從任何 App 的分享選單直接傳（最像 AirDrop）

**掃描並一鍵安裝（推薦）**

1. 用 iPhone 相機掃描電腦設定頁上的 QR Code。
2. 在打開的頁面按 **安裝捷徑**。這時上傳網址會自動複製，接著開始下載捷徑。
3. 點「加入捷徑」。在詢問網址的欄位 **長按 → 貼上**，完成。

捷徑檔是通用版，**裡面沒有你的 IP 或 Token**，網址是在加入捷徑時才填進去。

iPhone 只能匯入「已簽署」的捷徑，所以 `shortcut/傳到電腦.plist` 由 `sign-shortcut.ps1` 送到 RoutineHub 的 HubSign 服務簽署，產出 `shortcut/傳到電腦.shortcut`。只有修改捷徑內容時才需要重新簽署。

**手動建立（一鍵安裝失敗時使用）**

先在網頁的「加到分享選單」卡片中展開「手動複製網址」，按 **複製網址**，接著打開「捷徑」App：

1. 點 **＋** 新增捷徑，命名為「傳到電腦」，圖示可自由挑選。
2. 點下方的 **ⓘ**，開啟 **在共享表單中顯示**。
3. 最上面會出現「從 **共享表單** 接收 **圖片和其他…** 輸入」。點藍字類型，**全部勾選**，這樣任何 App 分享出來的東西都能接收。
4. 加入動作 **重複每個項目**，對象選「捷徑輸入」。
5. 在重複的區塊內加入動作 **取得 URL 內容**：
   - URL：貼上剛剛複製的網址（格式像 `http://192.168.1.20:8765/upload?token=xxxx`）。
   - 點「顯示更多」：**方法** 選 `POST`，**要求本文** 選 `表單`。
   - **新增欄位 → 檔案**，鍵輸入 `file`，值選「重複項目」。
6. 在重複區塊**外面**加入動作 **顯示通知**，內容填「已傳到電腦」。

用法：在任何 App 點分享 → 傳到電腦。

- **相簿**：可以多選，一次傳很多張。
- **LINE**：在聊天室打開照片、影片或檔案，點分享圖示（或「其他應用程式」）→ 傳到電腦。
- **檔案 App、Mail、Safari 下載的檔案、Office、PDF 閱讀器**：一樣點分享即可。

捷徑會用原本的檔名送出，沒有副檔名時，伺服器會依照檔案類型自動補上。

如果分享的是文字，會存成 .txt，同時複製到電腦剪貼簿。要傳連結的話，比較穩的方式是貼到網頁上的「傳送文字或連結」欄位，電腦就會收到並複製到剪貼簿。

### 在外面也想傳？

iPhone 也安裝 Tailscale，然後在設定頁點 Tailscale 那一行的位址，改用那個 QR Code 和網址，人不在家也能傳回這台電腦。

## 版本

版號統一寫在 `VERSION` 檔。電腦設定頁的「版本」欄會列出每個元件實際在跑的版本：

- **電腦服務**、**系統匣程式**：這兩個由 `安裝.cmd` 更新。
- **iPhone「傳到電腦」**、**iPhone「從電腦接收」**：捷徑每次連線都會回報自己的版本和使用時間，要從手機網頁重新安裝才會更新。

比電腦服務舊的元件會顯示成紅色。捷徑的選單標題（「傳到電腦 v1.6.0」）上也看得到版號。

改版時：修改 `VERSION` → 執行 `安裝.cmd`（重建系統匣程式、重新啟動服務）→ 執行 `sign-shortcut.ps1` 重新簽署捷徑 → 在 iPhone 重新安裝捷徑。

| 版本 | 內容 |
|---|---|
| 1.6.1 | 「從電腦接收」拿掉「如果」判斷（iOS 會遺失辭典值的比較文字），改由電腦先分好照片和檔案兩份清單 |
| 1.6.0 | 加入版號與設定頁的版本檢查；「從電腦接收」修正「請選擇此動作中每個參數的值」，其他檔案直接存到 Shortcuts 資料夾；iPhone 存好檔案才算已接收 |
| 1.5 | ntfy 推播與一鍵接收（臨時下載通行證） |
| 1.4 | 電腦傳到 iPhone（傳送到選單、收件匣）、雙向剪貼簿 |
| 1.3 | 網址分享後直接在電腦打開 |
| 1.2 | 開機自動接收、系統匣程式、存到「下載」、一鍵安裝捷徑 |
| 1.0 | 第一版：iPhone 傳檔案到電腦 |

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `server.ps1` | 接收伺服器（排程工作在開機時執行；`start.cmd` 可以手動在視窗中執行並看紀錄） |
| `Receiver.cs` | 檔名處理和串流式 multipart 解析（大型影片不會整個讀進記憶體） |
| `index.html` | 網頁：手機上是上傳頁，電腦上用 localhost 開啟則是狀態頁（加上 `?phone` 可在電腦上看手機版） |
| `Tray.cs` → `AirDropReceiver.exe` | 系統匣程式（用 Windows 內建的 .NET csc 編譯） |
| `build-icon.ps1` → `assets/` | 產生圖示（.ico 和 iPhone 主畫面用的 png） |
| `install.ps1` / `uninstall.ps1` | 安裝與移除 |
| `shortcut/build-shortcut.ps1` → `傳到電腦.plist` → `.shortcut` | 捷徑的產生腳本（要改捷徑請改這支）。`sign-shortcut.ps1` 會先產生 plist 再送去簽署，簽好的檔案由 `/shortcut` 提供下載 |
| `data/outbox/` | 要傳給 iPhone 的檔案（iPhone 收件匣） |
| `data/clip/` | 從 iPhone 傳來的最新一筆剪貼簿 |
| `config.json` | Token、埠號、儲存位置。刪除 `token` 欄位後重新安裝即可換一組 |
| `data/received.log` | 收件紀錄（系統匣通知和「最近收到」清單都讀這個檔案） |
| `下載\傳到電腦-文字.txt` | 收過的所有文字，依時間累積 |

## API

| 方法 | 路徑 | 說明 |
|---|---|---|
| POST | `/upload` | `multipart/form-data`（捷徑用），或直接把檔案內容當作 body，搭配 `X-Filename`（URL 編碼）標頭 |
| POST | `/text` | UTF-8 文字，會複製到電腦剪貼簿 |
| GET | `/api/ping` | 確認 Token 是否正確，回傳電腦名稱 |
| GET | `/api/info` | 僅限本機：Token、位址、最近收到的項目 |
| GET | `/api/health` | 健康檢查 |

除了 `/api/info` 和 `/api/health` 之外，所有 API 都需要 Token，可以放在 `X-Token` 標頭或 `?token=` 參數中。
